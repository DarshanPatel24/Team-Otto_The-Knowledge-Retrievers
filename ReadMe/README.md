# Team Otto – The Knowledge Retrievers

Single-page HTML5 deck. `index.html` holds all slides, images and the live Business Value Calculator (slide 8).
The video is the only external file: `assets/otto-intro.mp4` (slide 5, original quality).

Controls: ← / → keys, swipe, bottom buttons, `F` for fullscreen, `#8` style links jump to a slide.
